# Abartılı Sonsuz Otobüs Bekleme Simülatörü

## Bu Nedir?

Bu proje, insanlığın en büyük trajedilerinden birini simüle eder: **otobüs beklemek**.

Otobüs gelmez. Gelmez. Gelmez. Ama sen beklemeye devam edersin. Çünkü belki bu sefer gelir. Belki.

Bu simülatör, bilimsel metodoloji ile geliştirilmiştir (değildir). %100 gerçekçidir (değildir). Hayatını değiştirecektir (değiştirmez).

## Nasıl Çalıştırılır?

```bash
python simulator.py
```

Sonra beklemeye başla. Gerçek hayattaki gibi.

## Özellikler

- Otobüs asla gelmez (veya bazen gelir, kafa karıştırmak için)
- Gerçek zamanlı bekleme hissi
- Felsefi yorumlar
- İnsan ruhunu test eder

## Uyarı

Bu simülatörü çalıştırmak, gerçek hayatta otobüs bekleme alışkanlığını artırabilir. Risk size aittir.
